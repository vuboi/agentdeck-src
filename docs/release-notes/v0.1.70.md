### What's new

- Same features as 0.1.69 (OpenCode keeps one server per chat, Antigravity answers briefly and runs one process per turn, replies rise in).

### Fixes

- **Updates are signed with a new key.** The 0.1.69 build could not be signed, so this release replaces it. Installed apps from before this release need to be downloaded again.

### Developer notes

- Release version is `0.1.70`; the release workflow is triggered by the `v0.1.70` tag.
- Updater public key rotated in `apps/desktop/src-tauri/tauri.conf.json`; secrets `TAURI_SIGNING_PRIVATE_KEY` and `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` in `vuboi/agentdeck-src` were replaced.
