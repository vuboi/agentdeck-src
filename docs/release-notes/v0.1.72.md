### What's new

- **The chat says when an agent compacts its context.** When Claude, Codex or GitHub Copilot compacts its own context in the middle of a reply, the live line reads "Compressing context" instead of sitting on "Thinking", and a "Context compacted" line marks the spot in the reply once it is done.

### Fixes

- **Messages with images or file diffs draw again.** Some replies showed "This message could not be drawn" while their pictures or diffs were loading; those caches are no longer changed while the message renders.
- **Project activity and file search no longer retry in a loop.** A project folder that failed to load, and the background read of a project's files for search, kept starting again on their own.

### Developer notes

- Release version is `0.1.72`; the release workflow is triggered by the `v0.1.72` tag.
- Compaction reaches the chat as `AgentEvent::Raw` with label `compacting` / `compacted`: Claude `system` `status: "compacting"` and `compact_boundary` (`crates/adapters/src/agent/claude.rs`), Codex app-server `contextCompaction` item (`crates/adapters/src/agent/codex_server.rs`), Copilot `session.compaction_start` / `session.compaction_complete` (`apps/desktop/src-tauri/src/copilot.rs`).
- Not wired yet, no compaction event seen in their streams: Codex exec, OpenCode, WorkBuddy, Command Code, Antigravity, custom providers (`custom_chat.rs` does not compact history).
- The divider is a new `mark` block kind (`apps/desktop/src/lib/chat/mock.ts`, drawn in `ChatBlock.svelte`).
