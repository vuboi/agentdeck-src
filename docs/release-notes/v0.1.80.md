### What's new

- **Plans:** Keep project plans in `docs/plans/`, track their status and steps in the Plans panel, and create or update plans from chat with `/plan`, `/plans`, and plan tools. Plans from Claude and Codex plan mode are saved into the project.
- **Canvas:** Browse versioned HTML, SVG, Markdown and code artifacts in a project Canvas panel. HTML and SVG previews stay inside a restricted sandbox; artifacts are saved under `docs/artifacts/` and can be copied or saved as files.

### Fixes

- **Artifact fallback fences are idempotent across chat reloads.** Reopening a conversation returns the artifact already saved for that response instead of creating duplicates.
- **Concurrent artifact edits respect `base_version`.** Only one update based on the same version can be accepted; later updates receive a stale-version error.
