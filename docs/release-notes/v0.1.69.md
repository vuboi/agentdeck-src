### What's new

- **OpenCode chats keep their server open.** Each chat runs its own OpenCode server between turns, so a message takes about 2 s instead of 4 s. Its first turn starts while you are still typing.
- **Antigravity answers shorter.** Every message opens with a short instruction to answer briefly and do only what was asked, so Gemini stops narrating each step.
- **Antigravity turns start faster.** Each turn runs its own process again, which measured 6–7 s instead of 9–30 s with the kept process.
- **Replies rise in.** The first text of a reply fades and rises in as it appears, and a sent message settles in with a slight scale.

### Fixes

- **Stopping a turn ends its whole process tree.** A stopped or edited turn no longer leaves its tools or MCP servers running, and the next turn that resumes the same session no longer hangs.
- **A kept CLI that fails to start is cleaned up.** Its process tree is ended when the chat cannot talk to it, instead of being left running.

### Developer notes

- Release version is `0.1.69` once the version bump is committed; the release workflow is triggered by the `v0.1.69` tag.
- New `crates/adapters/src/agent/opencode_server.rs`: a private `opencode serve` per chat (loopback, password via `OPENCODE_PASSWORD`, idle 20 min, at most a fixed number kept). `OpenCode::args` uses `--server` when a server is attached and `--standalone` otherwise.
- Antigravity has no `warm_args` any more; `BREVITY` in `antigravity.rs` opens every turn. Test `agy_runs_one_process_per_turn` guards this.
- `kill_on_drop` is removed from the turn and warm-process spawns in `runner.rs` and `warm.rs`; `TreeGuard` and `kill_tree` end them.
