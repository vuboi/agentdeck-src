### What's new

- **Voice input shows a live wave.** While you record in the composer, a wave shows the input level.
- **Connectors show the latest CLI versions.** Settings > Connectors checks the newest version of each installed CLI.
- **Store discover page reworked.** The Store discover list is laid out again, with a new section structure.
- **Chat switching keeps recent chats ready.** The last few opened chats keep their messages in memory, so switching back to them is quicker.

### Fixes

- **Show in folder on Windows** selects the file in Explorer again, through the same path as path links.
- **Context auto-compress slider** keeps a fixed height, so the popover no longer jumps when it opens.
- **Chat history** stores its per-chat state in reactive maps, so the chat list updates when a chat changes.

### Developer notes

- Release version is `0.1.68`; the release workflow is triggered by the `v0.1.68` tag.
- Windows builds that compile `whisper-rs-sys` must run cargo through `scripts/win-cargo.cmd`. It needs VS 2022 BuildTools (C++ workload) and LLVM at `C:\Program Files\LLVM`.
- New Tauri command `connectors_latest_versions` (`apps/desktop/src-tauri/src/connectors.rs`), with its permission in `apps/desktop/src-tauri/permissions/autogenerated/connectors_latest_versions.toml`.
- Chat held-list rule: `apps/desktop/src/lib/chat/session/held.ts`.
