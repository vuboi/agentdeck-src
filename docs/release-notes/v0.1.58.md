### What's new

- **Native connector runtimes.** Expanded provider-specific connector and runtime support for Claude, Codex, Copilot, Antigravity, OpenCode and Muse Code, with clearer account, model and provider boundaries.
- **Project activity in the Work area.** Added durable project activity records and a dedicated activity view so background project work remains visible alongside task progress.
- **More reliable chat work lifecycle.** Refined provider protocol handling, session recovery, queued composer work and background task reporting across the desktop chat.
- **Image generation history.** Generated image candidates now preserve local file paths, restore more reliably after reload, and keep the selected model and variant details visible.

### Improvements & Fixes

- **Account and model refresh.** Account changes now invalidate stale model catalogs and refresh dependent model, effort and provider state.
- **Provider request handling.** Consolidated custom chat and provider request code with clearer response handling, quota support and safer connector logout paths.
- **Preview and local development.** Improved local server discovery, dynamic port handling, browser preview reuse and native permission coverage.
- **Chat media fallback.** Broken or undecodable chat images fall back to the bundled `image-not-found.png` asset instead of leaving a broken image element.
- **Image generator layout.** Variant previews now match the requested candidate count, and generation status, model name and render time are easier to read.

### Developer notes

- Added project activity, connector, provider and image generation changes across the desktop and Tauri layers.
- Release version is `0.1.58`; the release workflow is triggered by the `v0.1.58` tag.
