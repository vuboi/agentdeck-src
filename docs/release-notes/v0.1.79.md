### What's new

- None in this release.

### Fixes

- **A chat no longer stays hidden when it fails to show.** If the view of a reopened chat fails, the chat is shown with what it holds, instead of a blank panel.
- **Reading an old chat no longer loads more history by itself.** Coming back to a chat puts it where it was left, without reading older pages. Scrolling up reads the next page once the rows above are laid out, instead of reading page after page.

### Developer notes

- Release version is `0.1.79`; the release workflow is triggered by the `v0.1.79` tag.
- Changes: `apps/desktop/src/lib/components/chat/Chat.svelte` (reveal guard, `revealed` check on upward scroll, restore loop limit) and `apps/desktop/src/lib/chat/session/history.svelte.ts` (`loadingOlder` held until the rows settle).
- Not verified on a long chat: the blank/hang and the jitter while scrolling up were not reproduced in a debug build. The fixes above are guards against the mechanisms found in code.
