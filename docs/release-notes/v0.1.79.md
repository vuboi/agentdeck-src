### What's new

- None in this release.

### Fixes

- **A chat no longer stays hidden when it fails to show.** If the view of a reopened chat fails, the chat is shown with what it holds, instead of a blank panel.
- **Reopening a chat keeps what it already loaded.** Coming back to a chat puts it where it was left, without reading the whole history again or adding older messages to it.
- **Reading an old chat no longer loads more history by itself.** Scrolling up reads the next page once the rows above are laid out, instead of reading page after page.
- **A chat read from several files is no longer shown from its saved part first.** Forks and sub chats no longer jump when they finish loading.
- **Duplicate message keys no longer stop the chat from drawing.** The chat keeps drawing when a message id appears twice.
- **Scrollbars show again in the chat, network and file views.**
