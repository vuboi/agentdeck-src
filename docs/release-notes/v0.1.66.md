### What's new

- **`/btw` side questions.** Type `/btw <question>` in the composer to ask something on the side while the main chat keeps working. The answer shows in a panel above the composer. The side chat reads the conversation so far, runs in Claude's read-only plan mode, cannot delegate, and is closed (and its run stopped) when you close the panel or delete the parent chat. Claude only in this release.
- **Workers in their own git worktree.** A delegated task can run with `isolation: "worktree"`: the worker gets its own branch and folder under `.agentdeck/worktrees`, so its edits stay out of your checkout. The task card shows the branch with **Merge** and **Discard**. Merge goes only onto the branch the worker started from and only when its work is committed; a worker in a worktree is told to commit before it reports.
- **Chat history from more providers.** Past chats are read from more agent CLIs, mapped to their AgentDeck chats, and a Claude or Codex chat can be continued in its CLI.
- **Smoother running steps and text.** The running command line slides from one step to the next in place, and a long reply no longer rebuilds all of its steps for every word that streams in.

### Fixes

- **"This message could not be drawn" on every reply.** A reply that reached its first tool step failed to draw since v0.1.64; it is drawn again.
- **Claude failed to start on Windows** with `EISDIR: illegal operation on a directory, lstat 'E:'`. Node was started from a `\\?\` path; it now gets a plain one. The same applies to image generation scripts.
- **Tools and CLIs not found by agents on Windows.** The PATH given to agents keeps node and CLI folders first, no longer drops folders from a long PATH, and includes `mise`'s own folder so its shims work. `codex-auth list` errors now say why they failed.
- **Retries, reports and model switches.** A failed turn that is waiting to retry is no longer swallowed by a background report; a stopped chat no longer gets worker reports; a model picked while a turn runs is applied when the chat's turns end.
- **Task cards.** A sub-agent that ends in an error (Antigravity) is marked failed; background tasks are no longer marked stopped when an idle agent process is kept for reuse; a finished card from an older chat stays finished.
- **Theme switch** no longer leaves half the window in the old theme.
