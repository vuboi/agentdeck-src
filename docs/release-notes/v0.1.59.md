### Fixes

- **Reliable image reloads.** Generated image history now detects the actual PNG, JPEG, GIF or WebP bytes instead of trusting a filename extension, so older generated files with a `.png` path but WebP content remain viewable after reload or upgrade.
- **Safe image fallback.** Truly invalid or undecodable image files continue to fall back to the bundled `image-not-found.png` asset.
- **Persistent provider results.** OpenAI-compatible image URLs are downloaded to local generated-image storage before being written to history, avoiding expiring provider URLs.
