### What's new

- **Hidden subprocesses on Windows.** Suppress unwanted console window popups when Claude Code, OpenCode, and Antigravity execute Git Bash and CLI tasks on Windows (`CREATE_NO_WINDOW` and native wrapper launcher).
- **Middle-mouse pan navigation.** Add smooth middle-button drag panning across scrollable views including NetworkPanel, CodeView, DiffView, FileView, MediaView, and OfficePreview.
- **Enhanced Image Prompt Library and History.** Add pagination (`offset`/`limit`), prompt search, saved prompt library with local persistence, and redesigned image inspection modal.
- **Project Activity export.** Add native save dialog (`project_activity_save`) to export Markdown activity logs directly to chosen file paths.
- **Virtualized Activity Log.** Virtualize project activity items with sticky day headers and "Load older activity" pagination for smoother scrolling with large histories.

### Fixes

- **Codex session tracking.** Emit `AgentEvent::Session` immediately upon `thread.started` so the session ID is bound before later tool turns.
- **Windows Git process flags.** Ensure Git subprocess executions in Codex use hidden creation flags to prevent fleeting cmd/conhost popups.
- **Image prompt suggestion formatting.** Clamp prompt suggestions to exactly 5 distinct prompts with strict JSON formatting instructions.
- **Desktop compiler and clippy warnings.** Resolve unused fields in `ProviderQuota` and silence clippy argument count warnings on Tauri command handlers.
