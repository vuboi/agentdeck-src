### What's new

- **Recents shows placeholder rows while the chats load.** On start-up the chat list shows a short skeleton instead of an empty panel.

### Fixes

- **A model picked while a reply runs applies after that reply.** It also survives a reload, and the next message goes to the agent you picked instead of the agent of the chat before.
- **The prompt history button is gone from the chat input.** It stays in the image generator, where it belongs.
- **`/btw` is off in this release.** Its work continues on a separate branch.
