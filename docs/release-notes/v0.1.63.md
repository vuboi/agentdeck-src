### What's new

- **Reliable agent turn handling.** Improve streaming, interruption, stall recovery, output tails, warm starts, and session continuity across Claude, Codex, OpenCode, and Antigravity.
- **Additional agent connectors.** Add WorkBuddy and expand Antigravity connector setup, runtime handling, and model availability.
- **Clearer quota and workspace controls.** Improve quota display, connector settings, tabs, dock behavior, and sidebar navigation.
- **Claude agent packaging.** Bundle the Claude agent runtime with desktop builds.

### Fixes

- **Agent recovery and event ordering.** Strengthen guard, trace, permission, and continuation handling to reduce dropped or misordered agent events.
- **Connector runtime behavior.** Improve connector lifecycle and model selection across supported agents.
