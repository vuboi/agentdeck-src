### What's new

- **Changes from parallel runs are tracked in one place.** A file written by a side run, a sub-agent, a worker or your own save is recorded with the request that caused it. A chat shows a warning above the input when a run has overwritten a change from a newer request, with a button to put that change back.
- **Runs tell each other about file changes.** A run that is working on a file another run just changed is told about it, and a worker's parent gets the list of files its worker changed. A message you send to a side run is also passed to the main run.
- **Thinking shows how long it took.** Reasoning reads "Thinking" while it streams and "Thought for 8s" once done, in the same style in replies and in step groups.
- **Shell commands that run long move to the Work tray.** A shell command still running after 20 seconds releases the chat and shows in the Work tray; dev servers do so at once.

### Fixes

- **`delegate_task` without `agent` works.** It uses the agent of the chat that called it. Before, it failed with "agent is required".
- **Failed delegated tasks are counted separately.** The header of a delegated-work card shows "N failed" instead of counting them as complete.
- **Commits run the project's pre-commit hook again.** Git commands started by AgentDeck put the project's `node_modules/.bin` first on PATH and no longer pass on the `npm_*` variables of the pnpm run that started AgentDeck, so `lint-staged` resolves.
- **Retry notices no longer appear as reasoning.** Codex's "Reconnecting… 2/5" shows on the live line.
