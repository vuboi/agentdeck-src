# AgentDeck v0.1.82

## Harness runtime

- Provider-neutral lifecycle state for sessions, turns, tools, approvals and sub-agents.
- Shared stream/status projection across CLI, custom, Copilot, OpenCode, Command Code, Kimi, MiniMax, Z.AI and local runtimes.
- DSH SDK JSONL protocol framing with process-exit-safe shutdown.

## DSH plugin store

- MCP Store now includes the Awesome DSH Plugin catalog.
- Search and category filtering are available in the catalog panel.
- Install/remove delegates to the official `dsh plugin --profile sdk` commands, preserving DSH plugin compatibility.

## UI and providers

- Smoother stream rendering with Harness state and delta coalescing.
- Streaming caret is hidden while AI responds.
- Added local vLLM and Jan discovery plus MiniMax, Moonshot and Z.AI presets.

## Verification

- `cargo test -p ag-orchestrator`: 10 passed.
- `cargo test -p ag-adapters dsh_protocol -- --nocapture`: 5 passed.
- `pnpm --dir apps/desktop run check`: passed.
- Native desktop build remains dependent on the Windows Visual Studio/CMake and Whisper headers installed on the build machine.
