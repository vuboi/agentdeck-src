### What's new

- **Long-running work goes to Work.** Foreground shell flows such as builds, tests, dev servers, downloads, imports, syncs and waits now appear in the Work area while the chat lane is released for the next request.
- **More provider tool coverage.** Work detection covers Bash, Shell, PowerShell, terminal and exec tool names, including MCP-wrapped names and common transfer commands such as `curl` and `wget`.
- **WorkBuddy connector.** Add WorkBuddy / CodeBuddy sign-in detection, model discovery, image model discovery, image generation and connector installation.
- **More reliable multi-agent coordination.** Background tasks, hidden coordination turns and task reports now stay attached to their originating chat while other chats remain usable.
- **Faster connector settings.** Refresh only the connector tab being inspected and keep account, quota and model data scoped to the selected provider.

### Fixes

- **Work lifecycle completion.** Auto-promoted commands close when their synchronous result arrives instead of remaining stuck as background activity; provider-native background tasks keep their existing lifecycle.
- **Linux release builds.** Windows-only connector imports are now gated so Linux compilation does not fail on `CancellableChild`.
- **macOS release builds.** The deployment target is set to macOS 10.15 for the native whisper dependency and its supported system APIs.
- **Windows CLI discovery.** Native child processes now receive a usable PATH that can find Node, pnpm and managed CLI installations even when AgentDeck is started outside a developer shell.
- **Desktop dev launcher isolation.** Vite cache and native dev identities are isolated so multiple AgentDeck channels do not mix runtime chunks or app data.
- **History refresh stability.** A live chat remains selected when a provider history refresh temporarily omits its transcript.

### Developer notes
