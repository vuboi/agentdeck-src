### What's new

- **Sub-agent of another provider shows its logo.** A plugin sub-agent such as Codex's rescue agent is drawn with that provider's logo ("Codex · via Claude") instead of the generic robot.
- **The live line says what it waits for.** While a Claude reply only waits for its own background work, the line says "Waiting for 1 background task" instead of "Thinking".
- **Send while Claude works in the background.** When a Claude chat only waits for a background task it started, a new message goes straight to Claude and is answered in its own reply, instead of waiting in the queue. Other providers and messages that need a choice keep the queue.
- **Chats with several native files.** A chat that continued across providers (for example Claude, then Codex) shows the turns of every file, in time order, and exports all of them.
- **Propose a split of work.** When a request has independent parts, the agent can propose splitting it into parallel tasks. The chat shows a card with **Split into worktrees**, **Do it in this chat** and **Dismiss**; a split with overlapping files or dependencies runs in order.
- **Context auto-compress slider** uses the dot thumb, and its popover no longer jumps while it opens.
- **Show in folder** on a generated image selects the file in Explorer on Windows.

### Fixes

- **Image action menu** no longer lags when hovered: its app list loads when the menu opens.
- **`/btw`**: closing an empty draft also closes its side chat.
- **Retries, reports and model picks**: a saved model that is no longer offered stops the send with a message instead of running another model; a task that aborts still reports to its caller.
- **Worktrees**: a worker's processes are stopped before its worktree is removed.
- **Propose a split**: a split call keeps its whole input in the chat.
