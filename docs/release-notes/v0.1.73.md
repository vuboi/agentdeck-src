### What's new

- **Auto review of changed files.** After a main chat turn that changes two or more files, AgentDeck hands the diff to the agent routed for the review role, with a clean context. A FAIL verdict sends the lead agent back to fix it, and the fix is reviewed again, up to a set number of rounds. Turn it on in the model popover under Auto review.
- **Worktree bar in chat.** A chat that runs in its own git worktree shows the branch, how far it has moved from its base, and buttons to sync or finish the worktree.
- **Agents keep to the request.** Every agent (Claude, Codex, Copilot, OpenCode, Command Code, WorkBuddy, Antigravity and custom providers) is told to change only what was asked, to skip unrelated refactors, and to check its work before it reports back.

### Fixes

- **Antigravity no longer stops after one or two commands.** The stream stall that froze a chat and made its status jump lines is fixed. A real Antigravity run should still be checked end to end.
