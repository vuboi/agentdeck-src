### What's new

- **Per-chat auto-compress limit.** Choose the context size that triggers auto-compress for each chat (200k, 500k, or 1M tokens) from the context popover in the composer.
- **Task roles for delegation.** Add Security, Refactor, and Coding worker roles in Settings > Tasks. A delegated task can route by role alone, without naming an agent.
- **Claude Agent SDK bundled.** AgentDeck ships the Claude Agent SDK runner. Install Claude Code separately and sign in from Settings to use your Claude account.
- **Project activity log in app data.** The activity log moves out of each project's `.agentdeck` folder into AgentDeck's app data, keyed by project. Existing `.agentdeck/activity.md` files are migrated automatically.

### Fixes

- **Preview tabs.** A tab that a running chat is driving is no longer taken over by another chat. A finished chat releases its tab. Opening a page on the same server reuses one tab, and `localhost`, `127.0.0.1`, `0.0.0.0`, and `[::1]` count as the same server, so concurrent opens no longer create duplicate tabs.
- **Template addresses.** A copied template such as `http://localhost:{port}/` is rejected instead of opening a broken page.
- **Claude login.** `ANTHROPIC_API_KEY` and `ANTHROPIC_AUTH_TOKEN` inherited from the machine are removed before each Claude turn, so the local subscription login is used unless a key is selected for that turn.
- **Claude history.** Background task notifications written by the CLI no longer show up as messages you typed.
- **Claude binary lookup.** The Claude Code binary is resolved from `AGENTDECK_CLAUDE_CODE_BINARY` first, then from PATH.
- **Fallback routes.** Saved fallback rows resolve to the exact installed agent, model, and custom connector. A bare `custom` row shows no model instead of the first custom provider's model.
- **History import.** Projects are matched by path, so one Windows folder no longer produces two project rows.
- **File Changes list.** File names and folders share the row width evenly, so long names no longer squeeze the folder.

### Developer notes

- Release version is `0.1.64`; the release workflow is triggered by the `v0.1.64` tag.
- Added ESLint, lint-staged, and Husky. `pnpm hooks:install` now runs `pnpm exec husky`; the pre-commit hook keeps the staged junk-file guard.
- Theme diagnostics write style snapshots to the debug log when the window regains focus, becomes visible, or the theme drifts.
