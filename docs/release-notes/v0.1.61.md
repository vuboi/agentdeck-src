### What's new

- **WorkBuddy / CodeBuddy connector.** Add native sign-in detection, model discovery, image model discovery, image generation and connector installation.
- **More reliable multi-agent work.** Keep background tasks, delegated work, hidden coordination turns and task reports attached to their originating chats while other chats remain usable.
- **Work tray improvements.** Route long-running shell, build, test, download, import, sync and wait activity into Work with consistent completion, stop and reload state.
- **Provider and model routing.** Expand provider resolution, custom chat protocols, task-role routing, model metadata and native adapter support across Codex, Claude, OpenCode, Antigravity and custom providers.
- **Fallback and recovery controls.** Keep Settings and the chat model picker synchronized, carry the configured fallback model and effort into the next route, and default the chain to lightweight Haiku and GPT 5.6 Luna models at medium effort.
- **Activity log.** Add persistent project activity entries, grouped filtering and Markdown downloads, with model information in the detail header.
- **Composer polish.** Use the shared z-ui progress component for context usage and align context, voice-input and send controls.

### Fixes

- **History and session stability.** Preserve active chats, mixed-agent metadata, project identity and local work reports across provider refreshes, reloads and history imports.
- **Connector refreshes.** Scope detection, account, quota and model refreshes to the active connector, with safer cache invalidation and account switching.
- **Native runtime compatibility.** Improve Windows CLI PATH handling, platform-specific builds, warm adapter reuse, terminal/server lifecycle handling and image backend routing.
- **Browser and file UX.** Normalize preview addresses, close menus on scroll, preserve shared diff caches and improve image/file fallback behavior.
