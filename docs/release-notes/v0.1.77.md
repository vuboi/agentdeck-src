### What's new

- **Chat list opens at once.** The sidebar shows the last known chats right away on start, instead of a "Scanning AI agents" loader that covered them until every transcript was read.
- **Faster start-up scan.** Claude and Codex transcripts are indexed once; a transcript that has not changed is not read again.
- **Command Code and WorkBuddy get the AgentDeck browser.** Their agents can use `browser_serve` and the other browser tools, the same as Claude, Codex, OpenCode and Antigravity.

### Fixes

- **Long thinking labels stay on one line.** The "Thinking" row and the live status line are cut with "…" instead of wrapping onto a second line.
- **Markdown file opens with its text.** A file edited and then left in a tab no longer shows an empty editor in File view.
- **Background shell calls are recognised.** A Command Code shell command started with `run_in_background` is shown as background work.
- **Messages sent while work runs wait for the turn to end.** Outside Claude, a message sent during background work no longer stops the reply in progress.

### Developer notes

- Release version is `0.1.77`; the release workflow is triggered by the `v0.1.77` tag.
- History index: `crates/adapters/src/history/index_cache.rs` stores one file per source under `~/.agentdeck/history-index/` (`claude.json`, `codex.json`), keyed by path, length and modified time. Bump `VERSION` there when a parser's output changes.
- Command Code: `prepare()` in `crates/adapters/src/agent/commandcode.rs` writes `mcpServers.agentdeck` into the project's `.mcp.json`. Other servers stay; a file that is not a JSON object is left alone. The URL has no chat id, so chats in one project share a bridge.
- WorkBuddy (CodeBuddy CLI): `--mcp-config` with the same bridge URL, built in `crates/adapters/src/agent/workbuddy.rs`.
- `SERVE_CONTEXT` in `crates/adapters/src/agent/mod.rs` is the shared instruction to run dev servers through `browser_serve`.
- `canListenToSession` (`apps/desktop/src/lib/chat/session/run.svelte.ts`) returns true only for `claude`; other providers queue messages until the turn ends.
- `NO_DELEGATE_TOOLS` (`apps/desktop/src/lib/chat/session/turns.svelte.ts`) is empty: every built-in CLI has the bridge.
- Tests: `cargo test -p ag-adapters` (history cache, Command Code `.mcp.json`, WorkBuddy `--mcp-config`).
- Known gap: the question card is still hidden when a user message follows the question in the same chat (`pendingQuestion` in `Chat.svelte`). Not changed in this release.
- Known gap: Command Code and WorkBuddy bridge flags are not yet confirmed against a live CLI run; `browser_serve` has not been verified end to end.
