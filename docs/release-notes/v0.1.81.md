### What's new

- **Plans:** Keep project plans in `docs/plans/`, track their status and steps in the Plans panel, and create or update plans from chat with `/plan`, `/plans`, and plan tools. Plans from Claude and Codex plan mode are saved into the project. A chat in Plan mode stays held until you approve its plan; only you can approve it. Plan steps show their files, verify commands and evidence.
- **Canvas:** Browse versioned HTML, SVG, Markdown and code artifacts in a project Canvas panel. HTML and SVG previews stay inside a restricted sandbox; artifacts are saved under `docs/artifacts/` and can be copied or saved as files. The artifact picker pages and searches long lists.
- **Side view for sub agents:** Sub agents appear in a side view with a grid of their work and a composer for workers, so you can follow each one without leaving the chat.
- **Page memory per project:** The browser keeps what it learns about a site in each project's own SQLite database, out of that project's git history.
- **DOM-first browser control:** Preview finds and operates controls through the DOM before it falls back to screenshots.

### Fixes

- **Command Code stops installing itself at startup:** AgentDeck checked the CLI's sign-in with `command-code status --json` on every launch, without `--no-auto-update`, so the CLI ran its own background updater (an `npm i -g` into a second global copy). The status check now passes `--no-auto-update`.
- **A chat turn ends when it repeats the same tool call:** A stuck agent no longer loops on one tool call until the turn times out.
- **Stopping a background command no longer blocks:** Stop runs directly instead of on a blocking worker thread.
- **Finished sub agents stay in the grid:** The agents grid keeps finished sub agents and shows their transcript.
- **Artifact fallback fences are idempotent across chat reloads:** Reopening a conversation returns the artifact already saved for that response instead of creating duplicates.
- **Concurrent artifact edits respect `base_version`:** Only one update based on the same version is accepted; later updates receive a stale-version error.
- **Concurrent plan changes are serialized:** Shared plan mutations no longer overwrite each other.
- **Artifact saves keep the selected version:** Saving from the dialog stores the version you selected.
- **Code index stops growing without bound:** Indexes of projects that are no longer used are dropped after 7 idle days, and stale index files are deleted and pruned.
