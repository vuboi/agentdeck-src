### What's new

- **Command Code agent.** Command Code is a new agent in AgentDeck. Install its `command-code` CLI and sign in from Settings > Connectors. Its models come from the CLI, and it can be picked in the chat model picker or as the agent of a delegated task.

### Fixes

- None in this release.

### Developer notes

- Release version is `0.1.65`; the release workflow is triggered by the `v0.1.65` tag.
- The `command-code` CLI is pinned to `1.88.2` in `apps/desktop/src/lib/agents/endpoints.json` (`pins.commandCode`). The adapter is `crates/adapters/src/agent/commandcode.rs`; the connector is `apps/desktop/src-tauri/src/connectors/commandcode.rs`.
