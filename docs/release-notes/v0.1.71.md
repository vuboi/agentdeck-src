### What's new

- **One live line per running reply.** While an agent works, a single line says what it is doing now ("Thinking", "Running pnpm test", "Waiting for approval"), and says so when it only waits for a sub-agent or background shell.
- **Grouped command output.** Commands a reply ran are shown together in one group instead of one block each.
- **Agent CLIs update quietly in the background.** AgentDeck checks npm for newer CLI releases every hour and updates outdated ones one by one; a CLI with a chat turn running is left alone until a later check.

### Fixes

- **Antigravity tools are no longer blocked by hooks.** A global npm package that installs a command named `cmd` (such as `command-code`) took the place of Windows `cmd.exe` for agy, so every hook failed with "too many arguments" and all tools were refused. AgentDeck now puts the Windows system folders first on the PATH it gives agents.
- **Switching a chat to Antigravity no longer starts extra agy runs.** After an account switch, every switch to Antigravity re-checked its permission modes with three short agy turns; this now happens once per account switch.

### Developer notes

- Release version is `0.1.71`; the release workflow is triggered by the `v0.1.71` tag.
- Child PATH order changed in `crates/adapters/src/agent/resolve.rs` (`assemble_path`): system folders, then node folders, shared CLI folders, parent PATH.
- Antigravity mode probing: `apps/desktop/src/lib/agents/agy-modes.svelte.ts` (`loadAgyModes(accountEpoch)`).
- Local Windows builds of `whisper-rs-sys` need the VS 2022 Build Tools dev shell, `CMAKE_GENERATOR="Visual Studio 17 2022"` when VS 18 has no C++ tools, and `LIBCLANG_PATH` pointing at an LLVM whose `lib\clang` headers are present.
