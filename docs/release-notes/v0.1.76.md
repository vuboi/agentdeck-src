### What's new

- **Command Code and Muse Code each show one model row.** A subscription login and an API key for the same vendor now sit in one row. The model you pick decides which one runs, the same as Claude's account and credit models.

### Fixes

- **Connector check no longer shows a false error.** A repeat check of the same connector now waits for the check already running, instead of showing "Could not check the selected connector". The "Could not check installed connectors" banner clears after a successful check.

### Developer notes

- Release version is `0.1.76`; the release workflow is triggered by the `v0.1.76` tag.
- `vendorOf` (`apps/desktop/src/lib/agents/vendor-rows.ts`) matches a custom provider by parsed hostname: `api.commandcode.ai` for Command Code, `api.meta.ai` or `nativeAuth: 'muse-code'` for Muse Code. `modelSources` in `models.svelte.ts` uses it to build the merged rows.
- `joinRun` (`apps/desktop/src/lib/agents/check-runs.ts`) runs `refreshDetect` checks per key and releases the key when the run settles.
- Unit tests: `pnpm run test:connectors` (`vendor-rows.test.ts`, `check-runs.test.ts`).
- Known gap: the banner logic in `refreshDetect` (`connectors.svelte.ts`) is not covered by a test, because it depends on the Tauri store.
